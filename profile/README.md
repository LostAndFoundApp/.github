# Lost&Found

### Every lost thing deserves a way home.

Lost&Found is a community-driven mobile app designed to help people find and return lost belongings.

We’re building a simple, privacy-conscious way for people to:

- Report lost and found items
- Discover nearby items
- Get intelligent match suggestions
- Connect privately with potential owners or finders
- Coordinate safe handoffs
- Confirm when an item has been returned

## Our Approach

Lost&Found is built around three principles:

**Privacy**  
Precise locations and private verification details stay protected. Public discovery only exposes the information needed to help an item get home.

**Community**  
Returning a lost item should be simple, trustworthy, and centered around the people involved.

**Safety**  
Private communication, reporting, blocking, moderation, and controlled handoffs are built into the platform from the beginning.

## Building Lost&Found

Lost&Found is currently being developed with a focus on a secure, reliable V1 and a controlled initial launch.

We prioritize:

- Small, reviewable changes
- Feature-based development
- Server-side authorization
- Database-level security with RLS
- Automated validation
- Documented architectural decisions
- Safe and reversible releases
